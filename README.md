#  To-Do List Life Dashboard

A simple productivity dashboard built using HTML, CSS, and Vanilla JavaScript for the RevoU Coding Camp assignment.

##  Features

-  Dynamic Greeting
-  Real-time Clock & Date
-  25-minute Focus Timer
-  To-Do List
  - Add Task
  - Edit Task
  - Mark as Done
  - Delete Task
  - Local Storage
- 🔗 Quick Links
  - Add Links
  - Delete Links
  - Local Storage
-  Light / Dark Mode
-  Custom User Name
-  Prevent Duplicate Tasks

##  Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API
